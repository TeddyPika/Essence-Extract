# Essence-Extract

Claude Code skills for extracting the essence of documents and code.

## Install

Copy the skill folder you want from `.claude/skills/` into your project's `.claude/skills/` directory, or open this repository as your Claude Code project.

## Use

- **`vanilla-essence`**: Ask Claude to summarize a document, then provide or point to it. By default, it returns a one- or two-sentence summary and three to five key points.
- **`code-essence`**: Ask Claude to extract coding practices from a codebase or script, then provide or point to the relevant code. Findings are grounded in examples and distinguish existing conventions from possible improvements.
- **`roi-essence`**: Ask Claude to extract a project's return-on-investment case, including ROI, break-even, and payback when supported by the available inputs. It distinguishes stated facts from assumptions.
- **`safe-ai-essence`**: Ask Claude to extract an AI system's safety goals, risk areas, guardrails, and residual concerns from policies, system descriptions, or model documentation.
- **`security-essence`**: Ask Claude to summarize a system's security posture, assets, threats, implemented controls, and key gaps from code, design docs, or security reviews.
- **`risk-essence`**: Ask Claude to extract the principal risks, trade-offs, and failure modes from proposals, incident reports, or design documents.
- **`decision-essence`**: Ask Claude to summarize the decision being made, the options considered, and the reasoning behind the chosen path.
- **`policy-essence`**: Ask Claude to reduce a policy, process, or compliance document to its rules, obligations, exceptions, and enforcement points.
- **`architecture-essence`**: Ask Claude to extract the main system components, responsibilities, and relationships from code or design documents.
- **`user-need-essence`**: Ask Claude to turn feedback, tickets, or interviews into the underlying user problems and requirements.
- **`stock-essence`**: Ask Claude to extract the key revenue trends, business drivers, and market context from a company earnings report and related news.
